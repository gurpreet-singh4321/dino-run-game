# dino-run-game

🦖 **Dino Run Epochs** — A high-performance 2D endless arcade platformer built with Flutter and Flame Engine, featuring dynamic procedural biomes, rich parallax backgrounds, custom skins, power-ups, and immersive retro effects.

## 🌟 Key Features
- 🌋 **Dynamic Biomes**: Desert, Rain, Forest, Ice, Volcano, and Cosmos with multi-layered seamless parallax backdrops and rich procedural terrain strata.
- 🚀 **Space Mode & Jetpack**: Low-Earth orbit flight mode with high-tech sci-fi astronaut propulsion, plasma vector thrusters, and planetary orbital panoramas.
- 🔥 **Molten Lava Hazards**: Incandescent volcanic magma pits with bottom-up burning fire flames, fluid surface waves, and glowing ember sparks.
- 🦖 **Custom Skins & Animations**: Rive & procedural dino skins, collectible coin shop, power-ups (Shield, Magnet, Jetpack, Multipliers).
- 📱 **Cross-Platform**: Web, Android, iOS, Windows, macOS, Linux.
