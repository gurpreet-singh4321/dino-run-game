# Painted epoch artwork

Generated with the built-in image generation tool, using the approved Fossil Canyon as style reference. All five assets are connected to their live biome renderers. They are flattened panoramas, not separated parallax layers. Each uses alternating mirrored tiles and scales to the ground surface, matching the desert integration. Animated weather remains; procedural clouds and large god rays only render as fallbacks when painted artwork is unavailable. Space flight retains its separate background. Full-loop repetition, mobile performance and transition visual checks remain outstanding.
